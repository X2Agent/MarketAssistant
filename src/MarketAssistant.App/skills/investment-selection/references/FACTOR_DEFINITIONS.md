# 量化选股因子定义

## A股量化因子详细定义

### 质量因子（Quality Factors）

| 因子名称 | 计算公式 | 优先级 |
|---------|---------|-------|
| ROE_3Y | 近3年ROE均值 | 高 |
| ROE_稳定性 | 近3年ROE标准差（越小越好） | 高 |
| 毛利率_趋势 | (近年毛利率 - 3年前毛利率) / 3年前毛利率 | 中 |
| 净利率_趋势 | 同上（净利率） | 中 |
| 现金流质量 | 操作现金流 / 净利润 | 高 |

**质量因子选股标准**：
- ROE_3Y > 15%（权重：30%）
- ROE_稳定性标准差 < 3%（杜绝大幅波动）
- 现金流质量 > 0.8（利润有真实现金支撑）

---

### 成长因子（Growth Factors）

| 因子名称 | 计算公式 | 优先级 |
|---------|---------|-------|
| 营收增速_3Y_CAGR | (最新年营收/3年前营收)^(1/3) - 1 | 高 |
| 净利增速_3Y_CAGR | 同上（净利润） | 高 |
| 季度环比增速 | (本季净利润 - 上季净利润) / 上季净利润 | 中 |
| 分析师预期上调率 | 近三个月分析师上调预期次数 / 总预期次数 | 中 |

**成长因子选股标准**：
- 营收增速_3Y_CAGR > 15%
- 净利增速_3Y_CAGR > 15%
- 避免单季净利润同比下滑超过20%

---

### 估值因子（Valuation Factors）

| 因子名称 | 定义 | 使用场景 |
|---------|------|---------|
| PE（TTM） | 市值 / 近12个月净利润 | 盈利稳定公司 |
| PEG | PE / 净利润增速 | 成长型公司 |
| PB | 市值 / 净资产 | 重资产/银行 |
| PS | 市值 / 营收 | 高成长亏损公司 |

**估值因子筛选标准**：
- PE < 行业中位数 × 1.5
- PEG < 1.5（成长公司重点参考）
- PB < 行业中位数 × 1.3（价值类公司参考）

---

### 动量因子（Momentum Factors）

| 因子名称 | 计算周期 | 说明 |
|---------|---------|------|
| 价格动量_1M | 近1个月涨幅 | 短期趋势 |
| 价格动量_3M | 近3个月涨幅 | 中期趋势（主要参考） |
| 价格动量_12M | 近12个月涨幅 | 长期动量（避免追高） |
| 相对强度 | 个股涨幅 / 沪深300涨幅 | 个股vs市场强弱 |

**动量因子使用规则**：
- 3个月动量>0（表现优于市场），但12个月动量不超过150%（避免过热）
- 相对强度 > 1.2（个股跑赢市场20%以上）

---

### 风险因子（Risk Factors）— 负向筛选

以下出现任一条件，直接排除该标的：

| 风险项 | 排除条件 |
|-------|---------|
| 商誉 | 商誉 / 净资产 > 50% |
| 流动性 | 日成交额均值 < 5000万（流动性差） |
| 大股东减持 | 近3个月大股东减持比例 > 5% |
| 财务警示 | ST、*ST或被交易所质询财务问题 |
| 审计意见 | 非标准审计意见 |
| 诉讼风险 | 未决诉讼金额 > 净利润的30% |
| 负债风险 | 资产负债率 > 80%（非金融业） |
