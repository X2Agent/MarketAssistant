# 综合评分标准

## 技术面评分标准

| 评分 | 标准描述 |
|-----|---------|
| 9-10 | 多重突破确认（量价配合），多周期共振上涨，技术指标全线看多 |
| 7-8 | 清晰上升趋势，支撑有效，主要指标多头排列 |
| 5-6 | 震荡整理，无明显趋势方向，指标中性 |
| 3-4 | 下降趋势，阻力明显，主要指标空头排列 |
| 1-2 | 加速下跌，创新低，技术指标极度超卖或恐慌信号出现 |

## 基本面评分标准

| 评分 | 标准描述 |
|-----|---------|
| 9-10 | 行业龙头、宽护城河、高速增长（收入/利润增速>30%），估值合理 |
| 7-8 | 行业前三、清晰竞争优势、稳健增长（>15%），估值偏合理 |
| 5-6 | 行业前列但无突出优势，增长中性（5-15%），估值适中 |
| 3-4 | 行业竞争激烈、增长放缓（<5%）或估值偏高 |
| 1-2 | 行业衰退期、明显战略问题或估值严重高估 |

## 财务面评分标准

| 评分 | 标准描述 |
|-----|---------|
| 9-10 | 净利率>20%，ROE>20%，负债率<40%，自由现金流充裕，无财务风险 |
| 7-8 | 净利率10-20%，ROE15-20%，负债率40-60%，现金流健康 |
| 5-6 | 净利率5-10%，ROE8-15%，负债率60-70%，现金流中性 |
| 3-4 | 净利率<5%或下滑明显，ROE<8%，负债率>70%，现金流紧张 |
| 1-2 | 亏损、资不抵债或现金流极度紧张，存在财务造假风险 |

## 资金/情绪面评分标准

| 评分 | 标准描述 |
|-----|---------|
| 9-10 | 连续大幅净流入，机构集中增持，北向资金持续加仓，市场乐观情绪高涨 |
| 7-8 | 净流入为主，机构小幅增持，整体市场情绪偏积极 |
| 5-6 | 资金中性，机构持仓变化不大，市场情绪平稳 |
| 3-4 | 净流出为主，机构小幅减仓，市场情绪偏谨慎 |
| 1-2 | 持续大幅净流出，机构大规模减仓，恐慌情绪蔓延 |

## 消息面评分标准

| 评分 | 标准描述 |
|-----|---------|
| 9-10 | 重大利好事件（并购、重组、政策扶持、业绩大幅超预期）且可信度高 |
| 7-8 | 较明确的正面信息（合同签订、新品发布、业绩预增）可信度较高 |
| 5-6 | 无重大事件，或利好利空相互抵消 |
| 3-4 | 负面消息为主（合同纠纷、竞争加剧、业绩预警）可信度较高 |
| 1-2 | 重大负面事件（监管调查、核心客户流失、财务丑闻）可信度高 |
