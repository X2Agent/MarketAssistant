# 技术指标详细使用指南

## MACD（移动平均收敛/发散）

### 参数设置
- 标准：EMA(12)、EMA(26)、Signal(9)
- 短线变体：EMA(8)、EMA(17)、Signal(9)

### 信号解读
| 信号类型 | 形态描述 | 可信度 |
|---------|---------|---------|
| 金叉 | DIF从下方上穿DEA | 中 |
| 死叉 | DIF从上方下穿DEA | 中 |
| 顶背离 | 价格创新高但DIF未创新高 | 高 |
| 底背离 | 价格创新低但DIF未创新低 | 高 |
| 零轴上方金叉 | 多头市场，信号更可靠 | 高 |
| 零轴下方死叉 | 空头市场，信号更可靠 | 高 |

---

## RSI（相对强弱指标）

### 参数设置
- 标准：RSI(14)
- 短线：RSI(6)，长线：RSI(25)

### 信号解读
| RSI 值域 | 状态 | 操作参考 |
|---------|------|---------|
| >80 | 严重超买 | 考虑减仓或止盈 |
| 70-80 | 超买 | 警惕回调 |
| 50-70 | 多头区域 | 顺势持有 |
| 30-50 | 空头区域 | 谨慎操作 |
| 20-30 | 超卖 | 关注反弹机会 |
| <20 | 严重超卖 | 考虑逢低布局 |

**背离信号（优先于绝对值）**：
- 顶背离：价格更高，RSI更低 → 预警调整
- 底背离：价格更低，RSI更高 → 预警反弹

---

## KDJ（随机指标）

### 参数设置
- 标准：K(9)、D(3)、J(3)

### 信号解读
| 信号 | 条件 | 市场意义 |
|-----|------|---------|
| 超买 | K、D 同时 >80 | 短期注意回调 |
| 超卖 | K、D 同时 <20 | 短期注意反弹 |
| 金叉 | K线上穿D线，在20以下区域 | 超卖金叉，可靠看涨信号 |
| 死叉 | K线下穿D线，在80以上区域 | 超买死叉，可靠看跌信号 |
| J线极端 | J > 100 或 J < 0 | 短期极端信号，可能反转 |

---

## 布林带（BOLL / Bollinger Bands）

### 参数设置
- 标准：MA(20)，±2个标准差
- 窄带期（BB Squeeze）提示即将大幅波动

### 信号解读
| 价位 | 意义 |
|-----|------|
| 触及上轨 | 短期超买，若量缩则可能回落；若量增说明强势突破 |
| 触及下轨 | 短期超卖，若量缩则可能反弹；若量增说明加速下行 |
| 中轨（MA20） | 多头：中轨为支撑；空头：中轨为阻力 |
| 带宽极窄 | 盘整末期，即将发生方向性突破，等待信号确认 |

---

## 移动平均线（MA / EMA）

### A股关键均线

| 均线 | 意义 | 参考作用 |
|-----|------|---------|
| MA5/MA10 | 短期趋势 | 日内及短线方向 |
| MA20 | 月线趋势 | 短中期方向 |
| MA60 | 季线趋势 | 中线方向，反转信号 |
| MA250 | 年线趋势 | 牛熊分界线，长线方向 |

### 均线多头排列
MA5 > MA10 > MA20 > MA60 → 强多头趋势
均线空头排列：MA5 < MA10 < MA20 < MA60 → 强空头趋势

## 成交量分析

### 量价关系规则
| 价格方向 | 成交量 | 解读 |
|---------|-------|------|
| 上涨 | 放量 | 有效突破，趋势可信 |
| 上涨 | 缩量 | 上涨乏力，谨慎追高 |
| 下跌 | 放量 | 恐慌下行，关注止跌信号 |
| 下跌 | 缩量 | 正常回调，关注是否企稳 |
| 震荡 | 持续缩量 | 盘整积累，等待方向突破 |

### 异动量信号
- **天量**：成交量超过近20日均量的3倍，高度警惕主力出货
- **久缩后暴量上涨**：主力拉升启动信号
- **高位放量长上影线**：主力出货特征，看跌信号
