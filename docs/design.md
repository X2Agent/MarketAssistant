## 一、产品定位与核心设计哲学

### 1.1 产品定位
MarketAssistant 是一款面向高阶投资者与量化交易者的 **AI 原生金融市场工作站**。它横跨 **A 股市场**（严监管、T+1、交易时段限制、人民币计价）与 **虚拟币市场**（7×24小时、高波动、杠杆合约、USDT/BTC 计价），集成了多分析师协同（MAF Multi-Agent）、本地/外部知识库（RAG/MCP）、实时行情监控与自动化交易执行。

### 1.2 核心设计哲学
1. **金融终端的严谨 × 现代 SaaS 的克制**:
   - 杜绝花哨无意义动效，优先确保数据刷新时的极低渲染抖动与即时可读性。
   - 采用深色背景四层体系，减少长时间盯着盘面产生的眩光。
2. **AI 原生而非 AI 附庸 (AI-Native, Not AI-Addon)**:
   - 传统的 AI 助手往往只是一个悬浮侧边抽屉或独立聊天页，导致“看盘时无法对话，对话时看不到数据”。
   - MarketAssistant 将 AI 深度嵌入业务流：在资产页提供即时异动归因，在分析页提供分屏常驻伴侣（Docked Co-Pilot），在策略页提供 AI 参数回测与风险释义。
3. **闭环决策漏斗 (Closed-Loop Workflow)**:
   - 形成清晰的投资链路：**市场概览 (Home) → 标的初筛 (Screening) → 深度多智能体研判 (Analysis) → 策略回测与风控 (Strategy) → 执行与盯盘 (Trading/Alert)**。
4. **统一中的市场异构 (Dual-Market Cohesion)**:
   - 框架与交互结构统一，但底层字段、时间轴、风控维度按市场严格区分，不做生硬套用。

> **信息密度缺口已清零（v1.3）**：`AssetPageView` 已补齐行情速览指标面板、技术指标数值面板（MA/MACD/BOLL/KDJ）、盘口深度与逐笔成交四区块，见第六章 Phase 2.4。
> **A 股盘口已接入（v1.4）**：原"未接入"判断有误——同一 `hq.sinajs.cn` 接口对个股（如 `list=sh600519`）确实返回五档买卖盘，缺的只是解析与接入（`s_*` 为指数简版，不含盘口）。现已复用同一命名客户端实现 `SinaStockQuoteClient` + `AShareOrderBookService`，AssetPage 盘口区块对 A 股与 Crypto 均生效。
> ⚠️ 该接口无官方文档，故解析器带交叉校验（字段错位即判为无数据），绝不展示错误价格。
> **A 股逐笔成交不可用（v1.5 修正）**：v1.4 误判该接口含"成交明细"——实测字段 26..29 实为卖四/卖五档位，30 起为日期时间，**接口不提供逐笔**。据此假设解析出的"逐笔"只是卖盘档位（bug），已删除；A 股 `SupportsTickTrades=false`，资产页逐笔区块对 A 股隐藏，Crypto（币安成交流）不受影响。
> **K 线与行情速览双源级联（v1.5）**：智兔 `/hs/history` 不覆盖基金/ETF（实测 404 `{"error":"not found"}`），财联社 `/quote/stock/basic` 对 ETF 返回全 null。`AShareKLineService` 与 `AShareMarketSnapshotService` 均改为"智兔/财联社优先，失败回退新浪"（`SinaKLineClient` / `SinaStockQuoteClient` 快照字段），双源均无数据时给友好文案而非原始 API 错误。
> **资产详情页布局收敛（v1.6）**：顶部卡片移除 11 项行情速览指标行——开/高/低/收/涨跌幅/振幅/成交量/成交额改由 K 线图左上角图例**逐 bar** 展示（klinecharts `candle.tooltip.custom` 回调，涨跌幅自动按涨跌着色，日期去掉日/周/月 K 无意义的 00:00，大数字改万/亿）；技术指标（主图 MA(5/10/20/30/60)+BOLL 叠加，副图 VOL/MACD/KDJ）从右栏数值面板整体迁入图表，图例与副图随周期切换实时重算；右栏仅保留快照级指标（换手率/量比/市盈率/市净率，币安等不提供的市场显示空态）+ 盘口 + 逐笔；右栏区块由灰底 `SurfaceVariantBrush` 改为与主图一致的卡片样式，并通过 `ColumnSpacing` 补齐与 K 线卡片的间距。
> **资产详情页布局收敛（v1.5）**：顶部操作按钮（自选/快捷交易/价格预警/AI分析）紧随价格信息，不再横拉卡片留空；刷新移入图表工具栏；右栏折叠开关移入右栏顶部，折叠后主图区右侧留窄条展开入口；右栏空态只显示提示行，不再渲染表头/中间价/深度条。
> **资产详情页布局收敛（v1.7）**：① 顶部卡片收敛为单行——名称+代码在左、价格+涨跌幅紧随其后、操作按钮组靠右（删除独立"较昨收"标签）；② 右栏**去掉折叠机制恒显**（v1.5 的 28px 窄条展开入口观感突兀，已删除），宽度 320→360，顺序为**行情数据 → 盘口**；③ **逐笔成交区块从详情页移除**——该数据仅币安有（`/api/v3/trades`），A 股无数据源（`NoopTickTradeService`），右栏聚焦"行情数据 + 盘口"；`CryptoTickTradeService` 保留供 Agent 工具使用，VM 侧加载管线同步删除（避免页面加载时发起无展示的请求）；④ 盘口档位 5 → 10 档（币安；A 股新浪源固定五档，头部按实际返回档位标注"五档/十档"），并新增 5s 轮询计时器补偿 A 股无实时推送（币安仍由 miniTicker 推送驱动，轮询触发被 3s 节流跳过）；⑤ 行情数据卡片在快照指标全无值（ETF/基金，财联社对该类标的返回全 null）时整卡隐藏，不再显示"暂无数据"；⑥ K 线图表工具栏新增「指标」开关浮层（MA/BOLL/VOL/MACD/KDJ + 左上角图例显隐，经 `KLineChartView` 六个 styled property 下发 `setIndicatorVisibility`，副图指标动态 `createIndicator`/`removeIndicator`），仅当次会话生效；⑦ **顶栏按内容显隐**（`ShowTopBar = ShowIndexTickers || CanGoBack`）——非首页根页面顶栏此前只剩市场切换器、形成空白带，现整条隐藏；市场切换收敛为左侧导航栏 Logo 下方的**单个市场芯片**（当前市场名 + ⇄，点击切换，与 Ctrl+M 等价），Logo 恢复为纯品牌标识不再承载切换，避免"一个功能两个入口"。

## 三、信息架构与导航拓扑重构

### 3.1 导航链路拓扑图

```mermaid
flowchart LR
    subgraph Shell [主框架 MainWindow]
        NavRail[左侧导航轨 72px]
        TopBar[常驻顶栏 44px]
        ContentHost[页面承载容器]
    end

    subgraph Level1 [一级核心视图]
        HomePage[1. 综合看盘 Dashboard]
        FavPage[2. 自选看板 Watchlist]
        ScreenerPage[3. AI 选标的 Screener]
        AlertPage[4. 告警中心 AlertCenter]
        TradePage[5. 交易终端 Trading]
    end

    subgraph Level2 [二级深度工作区]
        AssetDetail[标的详情 AssetPage]
        DeepAnalysis[多分析师研判 AgentAnalysis]
        BalanceDetail[资产明细 BalancePage]
    end

    NavRail --> Level1
    HomePage -->|点击标的| AssetDetail
    FavPage -->|点击标的| AssetDetail
    ScreenerPage -->|一键研判| DeepAnalysis
    ScreenerPage -->|查看详情| AssetDetail
    AssetDetail -->|AI 综合研判| DeepAnalysis
    AssetDetail -->|快速建仓/策略| TradePage
    DeepAnalysis -->|采纳策略| TradePage
```

### 3.2 导航结构重构建议
1. **一级导航主项**：
   - `首页 (Dashboard)`: 市场总览、行情异动、快讯流、快捷搜索。
   - `自选 (Watchlist)`: 多分组管理、双视图切换（卡片视图 / 高密度网格表）。
   - `AI选标的 (Screener)`: 需求驱动选股、热点事件选股、量化指标初筛。
   - `交易 (Trading)`: 仅在当前市场能力支持时展示（Crypto 支持，A股隐藏或转为模拟盘/沙盘）。
   - `告警 (Alerts)`: 价格告警与风控联动门统一出口，带动态未读计数红点。
2. **底部固定项**：
   - `设置 (Settings)`: API 密钥、模型配置、知识库管理。
   - `关于 (About)`: 版本信息、环境状态。
3. **深度研判页 (AgentAnalysisPageView) 定位纠偏**：
   - 保持作为二级沉浸式工作区，但从 `AssetDetailPage` 与 `ScreenerPage` 均可平滑跳转，并在顶部提供明确的层级面包屑或返回按钮。

## 五、设计系统核心 Token 审计与收敛标准

针对当前代码库中未完全收敛的颜色与尺寸，强制执行如下映射规范：

### 5.1 文字与强调色 (On-Color)
- **绝对禁止使用纯文本字面量 `Foreground="White"`**。
- 一律引用 `{StaticResource TextOnEmphasisBrush}`。
- 当处于警告色或浅底容器时，文字需采用对应的语义文字刷（如 `WarningPanelTextBrush` / `SuccessPanelTextBrush`）。

### 5.2 数字字体规范
- 所有价格、涨跌百分比、成交量、资金数值一律指定：
  ```xml
  FontFamily="{StaticResource DataFontFamily}"
  ```
  该 Token 在深色主题下启用等宽对齐，严禁在个别控件中自行拼写 `"Consolas, 'Cascadia Mono'"`。

### 5.3 涨跌标签规范
- 摒弃早期“纯文字变色”方案，全面采纳“12% 透明度背景色块 + 同色加粗前景文字”：
  - 上涨标签背景：`{StaticResource BullishTagBackgroundBrush}`
  - 下跌标签背景：`{StaticResource BearishTagBackgroundBrush}`
  - 平盘标签背景：`{StaticResource NeutralTagBackgroundBrush}`
